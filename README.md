# eliminize.github.io

The player-facing site of ELIMINIZE: LIVE, published by GitHub Pages at <https://eliminize.github.io/>.

Plain static files, no build: `index.html`, `style.css`, `404.html` and the images in `assets/`.
`.nojekyll` makes Pages serve them as they are. Pages publishes `main` from the repository root.

To preview, open `index.html` in a browser, or serve the folder (`python -m http.server`) so `404.html`'s
root-relative links resolve.
